§01 核心特性

不只是「回答」，
而是「教会」

K Teach 把教学拆成可验证、可追踪、可复现的环节，让 AI 老师像人类老师一样有使命、有节奏、有证据。

F.01

使命驱动教学

先确立可观测的学习使命与成功标准，再围绕它设计每节「最小有用挑战」。

F.02

Lesson Bundle 单源

讲解、练习、反馈、检索规则统一存为权威源；渠道产物只能由它派生。

F.03

证据驱动学习

仅当学习者解释、检索、应用、迁移或纠正时，才记录「已论证学习」。

F.04

跨会话持久

学习工作空间跨会话保留使命、内容、证据与教学决策，续上进度继续教。

F.05

严格安全边界

凭据不入库、本地课程默认私有、公开发布需确认、产物发布后不可变。

F.06

平台中立

SKILL.md 是平台中立契约，Codex / ChatGPT / Claude / 任意智能体共用。

§02 教学循环

一个完整、可循环的教学闭环

从使命到证据，八步紧凑循环。每一步都可被 CLI 验证、被 Lesson Bundle 追溯。

01

确立学习使命

定义具体目标与可观测的成功标准，让教学有方向。

Mission
02

评估先验与偏好

检查已有知识、学习记录、可信来源与学习习惯。

Assess
03

选取最小有用挑战

选择略高于当前水平、又能即刻上手的任务。

Challenge
04

基于可信源核实事实

从权威原始来源校验每一个事实声明，杜绝编造。

Verify
05

构建 Lesson Bundle

聚焦单课能力：激活先验 → 精讲 → 实践 → 反馈 → 无回顾检索。

Bundle
06

选择教学媒介

文本、确定性 SVG 图表，或可选生成式视觉，按需组合。

Media
07

判定用途并生成

意图不明先问清：学习 / 微信 / PPT，三者各自独立派生。

Generate
08

记录已论证学习

把证据写回学习记录，驱动下一轮内容选择，循环继续。

Evidence
§03 多端输出

同一份课程，三端同生

Web 课程、HTML PPT、公众号文章都从同一个 Lesson Bundle 确定性派生，事实一致、来源可追溯。

WEB

Web 课程

本地静态学习网站，每节课可独立打开，含练习与检索检查。

  • 完整学习体验，离线可用
  • 7 套 Teaching Themes 可切换
  • paper / night / print 显示模式
PPT

HTML 演示

从 Presentation Brief 派生，含键盘导航与讲者备注。

  • 课堂教学 / 讲座分享双用途
  • 键盘导航 + 讲者备注
  • 与 Web 共享视觉主题
WX

公众号文章

从 Publication Brief 派生，需显式授权，平台安全表达。

  • 独立 Channel Theme
  • 草稿 / 预览 / 发布状态机
  • 不含练习，保持平台合规

§05 快速开始

三行命令，开启学习项目

全局安装持久 CLI，初始化 Learning Project，即可让 AI 接管教学。

bash
# 1. 全局安装持久 CLI
npm install -g k-teach@latest

# 2. 进入学习项目并初始化
cd your-learning-project
k-teach init

# 3. 指定 Agent 与首门 Teach（可选）
k-teach init --tools codex,claude --teach mathematics

# 本地预览（仅绑定 127.0.0.1）
k-teach preview --open
①
安装 CLI
全局安装 k-teach，获得确定性命令与预览能力。
②
初始化项目
生成 .k-teach/config.yaml、teachs/ 集合与初始 Teach。
③
接入 Agent
从同一份权威 Skill 生成各平台入口。
④
开始教学
对 Agent 说：「用 K Teach 帮我学分布式系统」。
